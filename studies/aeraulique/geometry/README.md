# Géométrie

Aucune géométrie réelle n'est fournie. Conserver les fichiers de travail dans
`local/`, puis documenter les unités, le repère, l'origine, la date, les sources,
les simplifications et les incertitudes avant de produire le maillage.

Les formats à retenir (par exemple STEP pour la CAO ou STL pour une surface)
dépendront du pipeline de maillage choisi. Ne pas confondre le fichier de
géométrie source et le maillage volumique utilisé pour le calcul.
