# Dictionnaires à créer

Définir `controlDict`, `fvSchemes`, `fvSolution` et les dictionnaires de maillage
selon le protocole retenu. `controlDict.example` fournit seulement l'en-tête et
un emplacement pour le solveur. Il doit être complété et renommé ; il ne
constitue pas une configuration exécutable.

Justifier notamment le domaine, les résolutions, les schémas, les critères
d'arrêt et, pour un calcul transitoire, le pas de temps.
