# Champs initiaux à créer

Créer les champs requis par le solveur retenu, leurs unités et toutes les
conditions aux limites. Pour de nombreux solveurs incompressibles, cela inclut
`U` et une pression cinématique `p`. Les champs turbulents ou thermiques
dépendent du modèle choisi. Aucune valeur ni sélection de modèle n'est fournie.
