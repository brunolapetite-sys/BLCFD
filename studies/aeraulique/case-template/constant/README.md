# Propriétés et géométrie à créer

Définir les propriétés physiques requises par la version OpenFOAM et le solveur
retenus, puis le modèle de turbulence/thermique s'il est justifié. Documenter
la provenance de la géométrie. Les noms de fichiers nécessaires dépendent du
solveur. Ne pas reprendre la viscosité artificielle du test de cavité.
